# Employee Attendance App

Android Studio project for a simple employee attendance system.

## Features
- Add employee ID, name and department
- Mark Present, Absent or Late
- Select attendance date
- Local Room database (offline)
- Monthly attendance report
- Long-press an employee to delete

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Use JDK 17.
4. Run on an Android phone/emulator.
5. To create APK: Build > Build APK(s).

The APK will normally appear under:
app/build/outputs/apk/debug/app-debug.apk
